# Angel Memories

**Official website:** https://angel-memories-official.vercel.app  
**Official Android APK:** https://angel-memories-official.vercel.app/download/Angel-Memories.apk

Angel Memories is a private photo and video memory gallery with a Royal Blue Glass + Gold interface.

## Privacy
- Each signed-in user can view and manage only their own gallery.
- Admin access is restricted to the configured administrator account.
- Uploaded media is stored in the private Supabase storage bucket.

## Main features
- Google sign-in
- Private photo and video uploads
- Preview, share, and delete your own media
- Personal albums and encrypted PIN vault
- Cloud backup and installable web app
- Android APK download

## Project
- Frontend: HTML, CSS, JavaScript
- Backend: Supabase Auth, Database, and Storage
- Hosting: Vercel
- Source: this repository
